### 기획 의도

강의 자료는 "이러면 위험하다"고 **말합니다.** 게임은 그것을 **겪게 합니다.** 플레이어가 직접 민감 정보를 붙여넣고, 그것이 시간이 지나 자신에게 돌아오는 것을 목격할 때 "멈추고 · 가리고 · 확인하기"는 지식이 아니라 반사신경이 됩니다.

### 핵심 한 문장

> 1회차에서 사고를 겪게 하고, 2회차에서 도구를 쥐여준다. 잔소리가 아니라 구원으로 느껴지게 만드는 것이 이 기획의 전부다.

### 빌려오는 것 / 바꾸는 것

**빌려온다**

- 플레이어의 행동이 시스템을 바꾸고, 바뀐 시스템이 플레이어에게 돌아오는 순환 구조
- 플레이어를 먼저 길들인 뒤 배신하는 레벨 디자인
- 정보가 화면에서 물리적으로 이동하는 것이 보이는 연출
- 도형 기반 아트와 최소한의 텍스트

**바꾼다 — 여기가 핵심 차이입니다**

원작은 **파국이 확정된 서사**입니다. 플레이어에게 선택권이 있는 것처럼 보이지만 다른 결말은 없습니다. 그게 원작의 힘이지만, 동시에 *"그래서 어쩌라고?"* 가 남습니다.

반면 Day 9 자료의 결론은 정반대입니다.

> "민감한 게 섞여 있다고 포기할 필요는 없어요. 가리고 바꿔서 안전하게 쓰면 됩니다." (14쪽)

그래서 **2회차 구조**를 도입합니다. 1회차는 원작처럼 파국으로 끝내되, 2회차에 도구를 쥐여주고 같은 하루를 다시 살게 합니다. **경각심(원작의 강점)과 해법(강의의 결론)을 둘 다 확보하기 위한 설계입니다.**

## 3. 코어 루프

```
    [붙여넣기]  →  [AI가 학습]  →  [AI가 세상에 답을 뱉음]
         ↑                                    ↓
    [나에게 돌아옴]  ←  [사람들이 그 답을 인용·확산]
                          (그 인용이 다시 학습 자료가 됨)

```

이 순환의 두 갈래가 게임의 두 파트다.

- **유출 고리** — 내가 넣은 개인정보가 낯선 사람의 화면에 나타난다 → *입력 위험*
- **환각 고리** — AI가 지어낸 숫자를 사람이 인용하고, 그 인용을 AI가 다시 근거로 삼는다 → *환각 검증*

두 번째 고리가 이 기획의 차별점이다. 환각이 사람을 거쳐 재학습되며 '사실'이 되어버리는 과정을 플레이어가 직접 가동시킨다. 원작에서 *"동그라미는 네모를 무서워한다"*가 보도를 통해 진짜가 되어버리는 것과 같은 구조다.

## 4. 전체 구조

### 1회차 · 프롤로그 「그냥 붙여넣는 하루」 (2분)

도구 없음. 게이지 없음. 경고 없음. 화면 속 사무실에서 텍스트를 드래그해 AI 창에 넣는 것만 가능하다. 넣을 때마다 일이 빨라지고 칭찬을 받는다. **게임이 플레이어를 길들이는 단계다.** (원작의 '멋진 모자' 구간과 같은 역할)

요청 4건 처리 → 화면이 어두워지며 시간이 흐름 → **두 개의 부메랑**

1. 낯선 사람의 AI 창에 1번 카드에서 넣었던 고객 이름과 번호가 떠오른다
2. AI가 지어낸 통계가 기사가 되고, 그 기사를 AI가 다시 인용한다

화면 정지. 한 줄만 남는다.

> **"다시 해보시겠습니까?"**

### 2회차 · 본편 「AI 안전 관제실」 (5분)

같은 하루가 반복된다. 이번엔 도구가 열려 있다.

- 이중 게이지 등장: `업무 완수` / `보안`
- 요청 6건 (1회차의 4건 + 신규 2건)
- 1회차에서 사고가 났던 그 요청이 다시 나온다 → **"아, 이거 아까 그거다"**가 학습의 순간

**메커니즘 4종이 난이도 순으로 배치된다.**


| 순서  | 메커니즘     | 하는 일                      | 대응 학습 내용    |
| --- | -------- | ------------------------- | ----------- |
| 1   | 위험 요소 클릭 | 프롬프트 안 위험 항목을 찾아 클릭       | 5대 위험 신호 인지 |
| 2   | 마스킹 에디터  | 드래그해 익명화·마스킹·요약·가상데이터로 치환 | 가려서 쓰는 4기법  |
| 3   | 의심 구간 밑줄 | AI 답변의 수치·출처·고유명사에 밑줄     | 환각 5대 위험지점  |
| 4   | 검증 도구 카드 | 턴당 2개만 사용 가능              | 4대 검증법      |

## 5. 이중 게이지 규칙

두 게이지 모두 0에서 시작해 100이 만점이다.


| 플레이어 행동     | 업무 완수          | 보안               |
| ----------- | -------------- | ---------------- |
| 요청을 그대로 처리  | +15            | **-20**          |
| 요청을 거절      | **0**          | 0                |
| 가려서 처리 (정답) | **+15**        | **0**            |
| 가리다 일부 놓침   | +15            | -8               |
| 검증 없이 답변 제출 | +15            | 후반 **-25** (부메랑) |
| 검증 도구 1개 사용 | **-3** (시간 소모) | —                |
| 환각을 잡아냄     | +5             | +5               |


### 설계 의도

- **전부 거절**하면 보안 100 / 업무 0 → *"안전한데 아무 일도 못 했다"*
- **전부 그대로**하면 업무 90 / 보안 0 → 1회차 재현
- **가려서 처리**해야만 양쪽 모두 확보 → 강의 자료의 결론과 일치

검증 도구에 업무 비용(-3)을 붙인 이유는 **어디를 의심할지 고르는 판단력**까지 훈련시키기 위함이다. 턴당 2개 제한이 있으므로 5개 밑줄 중 진짜 위험한 2개를 골라야 한다.

## 6. 요청 카드 6장

각 카드는 `[상황 · 원본 · 위험요소 · 1회차 결과 · 2회차 정답]` 구조를 갖는다.

### 카드 1 — 고객 문의 요약 ★1회차 등장

- **상황**: "이번 주 고객 문의 30건, 유형별로 정리해줘"
- **원본**: 이름 · 전화번호 · 주문번호가 그대로 담긴 문의 목록
- **위험 요소**: 실명(3곳), 전화번호(3곳), 주문번호(2곳)
- **1회차 결과**: 후반부, 낯선 사람의 AI 창에 `김OO 010-1234-XXXX`가 그대로 출력됨
- **2회차 정답**: 이름 → `고객 A·B·C`, 번호 → `010-****` 마스킹 후 전송
- **피드백 문구**: *"결과물은 똑같이 얻었습니다. 원본을 다 줄 필요가 없었던 거죠."*

### 카드 2 — 회의록 정리 ★1회차 등장

- **상황**: "어제 회의록 통째로 넣을 테니 액션 아이템만 뽑아줘"
- **원본**: 참석자 실명, 미공개 실적 수치, 인사 관련 발언
- **위험 요소**: 실명(5곳), 미공개 실적(2곳), 인사 논의(1곳)
- **1회차 결과**: 미공개 실적이 AI의 다른 답변에서 인용되어 등장
- **2회차 정답**: 원문 대신 **요약만** 넣기 — 직책으로 치환, 수치는 제외
- **피드백 문구**: *"이 결과를 만들 수만 있으면 되지, 원본을 다 줄 필요는 없습니다."*

### 카드 3 — 경쟁사 뉴스 요약 ★1회차 등장 · 함정 없음

- **상황**: "공개된 경쟁사 뉴스 3건 요약해줘"
- **원본**: 공개 기사
- **위험 요소**: **없음** — 입력은 안전하다
- **함정**: AI **답변**에 `"업계 관계자의 73%가..."`라는 출처 없는 통계가 섞여 있다
- **1회차 결과**: 그대로 보고서에 넣음 → 후반부에 그 숫자가 기사가 되어 돌아옴
- **2회차 정답**: 수치에 밑줄 → `근거 요구` 도구 사용 → AI가 "출처를 확인할 수 없습니다" 실토
- **역할**: **입력이 안전해도 출력은 안전하지 않다**를 가르치는 전환점 카드

### 카드 4 — 신제품 사양 정리 ★1회차 등장

- **상황**: "아직 발표 안 한 신제품 사양, 보도자료용으로 다듬어줘"
- **원본**: 미공개 스펙, 출시일, 가격
- **위험 요소**: 미공개 정보 전체
- **1회차 결과**: 경쟁사 담당자의 AI 창에 유사 스펙이 등장
- **2회차 정답**: **가상 데이터**로 치환 — 실제 수치를 비슷한 가짜로 바꿔 문체만 다듬기

### 카드 5 — 지원자 서류 검토 ★2회차 신규

- **상황**: "지원자 12명 이력서 넣을 테니 순위 매겨줘"
- **원본**: 실명, 학교, 나이, 사진, 주소
- **위험 요소**: 개인정보 + **AI의 편향 판단**
- **2회차 정답**: 익명화 후 → 답변의 순위 근거에 밑줄 → `자가 검토` 도구로 편향 확인
- **역할**: 개인정보와 환각을 **한 카드에서 동시에** 다루는 종합 문제

### 카드 6 — 계약 조항 확인 ★2회차 신규 · 최종

- **상황**: "이 조항이 법적으로 문제없는지 확인해줘"
- **원본**: 계약서 전문 (거래처명, 금액, 기밀 조항)
- **위험 요소**: 기밀 문서 전체 + AI가 **없는 법 조항을 지어냄**
- **2회차 정답**: 핵심 조항만 발췌·익명화 → 인용된 법 조항에 밑줄 → `교차 확인` 도구
- **역할**: 배운 것 전부를 한 번에 쓰는 최종 관문

```
└──────────────────────────────────────────────────────┘

```

### 아트 방향

원작의 단순 도형 문법을 차용한다. 사람은 동그라미, 말풍선은 사각형, 문서는 선. **핵심 연출은 "정보가 물리적으로 이동하는 것을 보이게 하는 것"이다.**

- 붙여넣은 텍스트는 AI 안에 **작은 점**으로 쌓인다 (누적이 눈에 보임)
- 후반부, 그 점이 다른 사람 말풍선에서 **다시 튀어나온다**
- 파국 시 화면의 모든 말풍선이 AI가 만든 문장으로 채워진다

### 사운드 / 연출

- 붙여넣기: **딸깍** (원작의 셔터음 대응)
- AI 학습: 점이 빨려 들어가는 짧은 애니메이션
- 부메랑 순간: 소리 없음. **정적**이 가장 강한 연출이다.

## 8. 확신 배지 규칙 (별도 메커니즘 아님, 문제 작성 규칙)

AI 답변마다 배지를 붙인다: `⭐ 확실합니다` / `아마도` / `확인이 필요합니다`

**규칙: 오답과 환각은 항상** `⭐ 확실합니다` **쪽에 숨긴다.**

플레이어는 두세 판 만에 스스로 깨닫는다 — *확신 표시를 믿으면 안 되는구나.* 설명 없이 규칙만으로 가르치는 방식이며, 구현 비용은 문구 추가뿐이다.

> "AI가 자신 있게 말한다고 해서 맞는 건 아니에요. 오히려 가장 그럴듯할 때가 제일 위험합니다." (Day 9, 19쪽)

## 9. 보조 장치 2종

자료 대조 결과 메커니즘에 담기지 않은 학습 내용 두 가지를, 저비용 장치로 회수한다.

### (1) 멈추기 확인창 — 자료 10쪽

2회차에서 [전송] 버튼을 누르면 확인창이 한 번 뜬다.

```
        "이 내용, 밖에 나가도 괜찮은 걸까?"

              [ 그냥 보내기 ]   [ 다시 보기 ]

```

- **1회차에는 이 창이 없다.** 2회차에 처음 등장한다 — 이 차이 자체가 '멈추기 습관'의 시각화다
- 3장째부터는 창을 끌 수 있게 한다 (`다시 묻지 않기`). 습관이 몸에 붙었다는 신호를 플레이어가 스스로 선언하게 만든다
- 구현 비용: 모달 하나

### (2) 플랜 표시 — 자료 8쪽

게임 시작 시 우측 상단에 작게 표시한다: `사용 중: 무료 플랜`

- 2회차 중반, AI 창 구석에 **⚙ 설정 아이콘**이 나타난다
- 열어보면 `대화 내용을 학습에 사용` 스위치가 **켜져 있다**
- 이걸 발견해서 끄면 보너스 (보안 +10). 못 보고 지나가도 게임은 진행된다
- 엔딩에서 안 껐다면 한 줄: *"설정에 학습 사용을 끄는 옵션이 있었습니다. 무료·유료·기업용은 정책이 다릅니다."*

**숨겨둔 이유**: 이 내용은 판정 문제로 만들면 지루하다. **발견하는 재미**로 바꾸면 오래 기억된다.

## 10. 엔딩

### 결과 화면 — 4분면 등급


|           | 보안 낮음 | 보안 높음            |
| --------- | ----- | ---------------- |
| **업무 높음** | 유출 사고 | **AI 네이티브** ← 목표 |
| **업무 낮음** | 최악    | 안전한 무능           |


각 사분면마다 다른 한 줄 코멘트를 띄운다. `안전한 무능` 칸에는 특히 이렇게: *"안전했지만, 아무 일도 못 했습니다. 가려서 쓰면 둘 다 가능했어요."*

### 산출물 1 — 내 직무 안전 카드

플레이 로그를 기반으로 개인화한다.

```
┌─────────────────────────────────┐
│  당신이 가장 자주 놓친 것        │
│  → 미공개 정보 (3회)             │
│                                 │
│  당신의 직무에서 특히 조심할 것  │
│  → [HR / PO / 디자인 / 개발 선택] │
│                                 │
│  오늘의 안전 3습관               │
│  멈추기 · 가리기 · 확인하기      │
└─────────────────────────────────┘

```

이미지로 저장 / 공유 가능하게 한다.

### 산출물 2 — 검증 프롬프트 복사 버튼

Day 9 자료 23쪽의 4문장을 그대로, 클릭 한 번에 복사된다.

```
· 답의 근거와 출처를 함께 표시해줘.
· 확실하지 않으면 '모른다'고 말해줘.
· 이 자료 안에서만 답하고, 없는 건 지어내지 마.
· 방금 답에서 틀릴 수 있는 부분을 스스로 짚어줘.

```

**[ 복사하기 ]** 버튼 하나. 이게 게임의 마지막 화면에 남는다.

## 13. 미해결 과제

- 1회차 부메랑이 2분 안에 설득력 있게 전달되는가? (너무 빠르면 우연처럼 보인다)
